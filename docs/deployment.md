# פריסה ב־Render

## לפני שמתחילים

צריך מפתח Gemini API פעיל מ־Google AI Studio. מומלץ להגדיר מגבלת שימוש
והתראת חיוב בחשבון Google.

## Blueprint

הקובץ render.yaml יוצר:

- שירות Web בתוכנית Starter, משום ששירות שנרדם אינו מתאים לשיחת טלפון נכנסת.
- דיסק קבוע של 1GB עבור מסד נתוני ההתקדמות.
- סוד אקראי עבור ממשק הדוחות.
- תמלילים כבויים.

ב־Render:

1. New → Blueprint.
2. בוחרים את המאגר ZACK770/English-Teacher.
3. מאשרים את השירות.
4. מזינים GEMINI_API_KEY. אין לשמור את המפתח ב־GitHub.
5. ממתינים שה־Deploy יהפוך ל־Live.
6. פותחים https://<domain>/readyz ומוודאים שמתקבל status ready.

## חיבור טכנוליין

נקודת הקצה היא:

~~~text
wss://<render-domain>/v1/technoline/stream
~~~

למורה הנפרד למבוגר יש ליצור ערוץ גולמי נוסף, לשמור את המזהה שלו במשתנה
`TECHNOLINE_ADULT_CHANNEL_ID`, ולהפנות אותו אל:

~~~text
wss://<render-domain>/v1/technoline/stream/adult
~~~

משאירים את שדה סוד האימות של טכנוליין ריק. אימות Bearer כבוי כברירת מחדל.
מזהה הערוץ משמש רק לבדיקת מסגרת הפתיחה ואינו סוד.

מזהה הערוץ נשאר 2614d922d06b4f.

מומלץ לבצע שיחת בדיקה קצרה ולבדוק את יומני Render. אין להפעיל לכידת אודיו
בסביבת הייצור.

## NetFree

לאחר הפריסה, מסלול השיחה הוא טכנוליין → Render → Google; הוא אינו עובר דרך
המחשב הביתי או דרך חיבור NetFree. NetFree עשוי להשפיע על פתיחת לוח הבקרה או
Google AI Studio, אך לא על השיחה עצמה.

## עלויות וזמינות

שירות קבוע בתוכנית Starter מתאים יותר משרת חינמי שנרדם. הדיסק נחוץ כדי
שהתקדמות הלימוד לא תימחק בפריסה מחדש. יש לבדוק את מחיר Render העדכני לפני
אישור ה־Blueprint.

## עדכון

כל push לענף main מפעיל פריסה אוטומטית. לאחר שינוי משמעותי מריצים:

~~~bash
ruff check .
pytest -q
~~~
