# English Teacher — מורה קולית דרך טכנוליין

שרת מאובטח שמחבר ערוץ סטרימינג גולמי של טכנוליין אל Gemini Live ומפעיל מורה
קולית לאנגלית לתלמידת כיתה ח'. המורה מנהלת שיחה קצרה וטבעית, מתקנת טעויות
בעדינות, מתאימה את הרמה ושומרת תצפיות לימודיות קצרות בין שיעורים.

הפרויקט אינו מוצר רשמי של טכנוליין או Google.

## מה כלול

- WebSocket ציבורי עבור טכנוליין; אימות Bearer כבוי כברירת מחדל.
- אימות נפרד של מזהה הערוץ 2614d922d06b4f — הוא מזהה, לא סוד.
- תמיכה בפרוטוקול שנמדד: PCM16LE, מונו, 8kHz, מסגרת של 320 בתים בכל 20ms.
- המרה רציפה 8kHz → 16kHz עבור Gemini ו־24kHz → 8kHz עבור המרכזייה.
- שליחת אודיו חזרה בקצב קבוע וקטיעת תשובה כאשר התלמידה מתחילה לדבר.
- Gemini 3.8 Live כברירת מחדל, עם VAD מותאם לשיחת טלפון.
- רגישות התחלת דיבור נמוכה יותר כדי שנשימות ורעשי חדר קצרים לא יקטעו את המורה.
- כל ההוראות, ההסברים, התיקונים והסיכומים בעברית; האנגלית נשמרת לתרגול עצמו.
- SQLite למעקב התקדמות, ניקוד וסיכומי שיחות. תמלילים אינם נשמרים כברירת מחדל.
- לוח הורה מוגן המציג הצלחה, נקודות ועלות Gemini משוערת, ומשמש גם כמרכז
  שליטה דינמי בפרומפט, מטרת הלמידה, מדיניות הסיום, הקול והגדרות זיהוי הדיבור.
- בדיקות, Docker ו־Blueprint מוכן ל־Render.

## פריסה מהירה ב־Render

1. ב־Render בוחרים **New → Blueprint** ומחברים את המאגר הזה.
2. Render קורא את render.yaml ויוצר שירות בשם technoline-english-teacher.
3. מזינים רק את GEMINI_API_KEY כאשר Render מבקש אותו.
4. לאחר שהשירות עלה, בודקים:

   ~~~text
   https://<render-domain>/readyz
   ~~~

5. בטכנוליין מגדירים:

   ~~~text
   WebSocket endpoint: wss://<render-domain>/v1/technoline/stream
   Authentication secret: להשאיר ריק
   Channel token: 2614d922d06b4f
   ~~~

### מורה נפרד למבוגר

אותו שרת תומך בפרופיל נפרד למבוגר, עם פרומפט, הגדרות דיבור, היסטוריה,
ניקוד ועלות עצמאיים. יוצרים בטכנוליין ערוץ גולמי שני ומגדירים ב־Render את
`TECHNOLINE_ADULT_CHANNEL_ID` לפי מזהה הערוץ החדש. נקודת הקצה שלו היא:

~~~text
wss://<render-domain>/v1/technoline/stream/adult
~~~

אין להזין את מזהה הערוץ כסוד Bearer. לאחר שמירת המשתנה ניתן לבחור בכותרת לוח
הניהול בין "המורה של הבת" לבין "המורה שלי" ולנהל כל אחד בנפרד.

אין כתובת wss מדויקת לפני ש־Render מסיים את הפריסה ומקצה דומיין.
הוראות מלאות נמצאות ב־[docs/deployment.md](docs/deployment.md).

## הפעלה מקומית

נדרש Python 3.12 ומעלה:

~~~bash
python -m venv .venv
pip install -e ".[test]"
cp .env.example .env
uvicorn app.main:app --host 127.0.0.1 --port 8080
~~~

יש ליצור סוד מנהל באורך 32 תווים לפחות:

~~~bash
python scripts/generate_secret.py
~~~

שומרים אותו ב־.env תחת ADMIN_BEARER_SECRET.
את מפתח Gemini שומרים רק במשתני הסביבה.

## דוח התקדמות

ממשק נוח להורה זמין בכתובת:

~~~text
https://<render-domain>/dashboard
~~~

בכניסה מזינים את הערך של `ADMIN_BEARER_SECRET` השמור ב־Render. הסוד נשמר רק
בלשונית הדפדפן הנוכחית. הלוח מציג סיכומי שיחות, נקודות, הצלחות, יעד להמשך ועלות
Gemini משוערת. העלות היא חישוב לפי נתוני השימוש והמחירים המוגדרים באפליקציה;
החיוב בפועל בחשבון Google הוא הקובע.

אזור "יומן טכני" מציג אירועי חיבור ותורות שיחה, דחיית חיבור כפול וזיהוי
אפשרי של תגובה ללא דיבור חדש. היומן אינו שומר אודיו או את תוכן התמלילים,
ולכן העלות והעומס שלו זניחים ביחס לשיחת האודיו עצמה.

השינויים במרכז השליטה נשמרים במסד הנתונים וחלים על השיחה החדשה הבאה ללא
דיפלוי. בתחתית הלוח מוצגים לקריאה בלבד פרומפט המערכת האפקטיבי, הודעת הפתיחה,
הודעת ה־setup המלאה ל־Gemini והפרטים הטכניים שאינם ניתנים לשינוי דינמי.

~~~bash
curl -H "Authorization: Bearer <ADMIN_BEARER_SECRET>" https://<render-domain>/v1/progress/student
~~~

הדוח כולל זמני תרגול, מספר תורות, ניקוד, עלות משוערת ותצפיות לפי מיומנות. המורה מקבלת בתחילת
השיחה הבאה את סך הנקודות מכל ההיסטוריה, צעדי ההמשך האחרונים ותקציר פרטי וקצר
של התצפיות הקודמות. אין לשים שם, מספר טלפון או
שם בית ספר בתוך STUDENT_ID.

## בדיקות

~~~

## פרטיות

- אודיו גולמי משיחות אינו נשמר. קובצי קריינות שנוצרו במנהל נשמרים להורדה.
- תמלילי קלט ופלט ופרומפטים מדויקים נשמרים בלוגים. STORE_TRANSCRIPTS שולט בעותק נוסף בסיכום.
- מספר המתקשר נשמר בתיק הלקוח לצורך חשבון אחיד; הוא אינו מוכנס לפרומפט.
- המורה מונחית לא לבקש שם מלא, כתובת, מוסד לימודים, סיסמאות או מספרי טלפון.

## מרכז ניהול המיזם

`/dashboard` הוא הממשק החדש. המסך הקודם זמין זמנית ב־`/dashboard/legacy`.
הכניסה משתמשת בערך `ADMIN_BEARER_SECRET` שמוגדר בסביבת השרת.
הממשק כולל לקוחות, בוטים, מסלולים, חבילות, רישום תשלומים ידני, קריינות,
לוגים, חציון ו־P95 לזמני חיבור ואודיו, והנחות עסקיות עם תרחישי 100/500/1000 לקוחות.
נתוני שיחות חדשים מקושרים לאדם דרך מספר המתקשר. היסטוריית למידה אינה משותפת לכל משתמשי הבוט.
שיחות ישנות אינן משויכות אוטומטית לאנשים; אין להסיק להן זהות מתוך שם הבוט.

לכל בוט כתובת WebSocket ב־`/v1/technoline/stream/bots/{bot_id}`.
הנתיבים הישנים נשמרו. שינוי הגדרות מפרסם גרסה; חזרה לגרסה קודמת יוצרת גרסה חדשה.
תצוגה ללא פרסום משתמשת באותו compiler כמו השיחה החיה, בלי לשנות את הגרסה הפעילה.

מדיניות דקות ומכסות מופעלת בנפרד לכל בוט, והיא כבויה כברירת מחדל בערוצים קיימים.
המדיניות בודקת תוקף, שומרת דקות אטומית לשיחה ומחזירה יתרה שלא נוצלה.
שיחות חינם מוגבלות לפי חשבון וחודש. לא ניתן להשתמש במכסת חינם כמספר חסוי.
בסיום המכסה מתבצעת העברה לשלוחה שהמנהל הגדיר; יש להכין את תוכן השלוחה בטכנוליין.
רישום תשלום ידני אינו מחייב כרטיס אשראי ואינו מנפיק קבלה חשבונאית.

`/learn` הוא אזור התלמיד: קישור אישי לשבעה ימים מופק מתיק הלקוח,
וקישור חדש מבטל את הקודם. התרגול הראשוני באתר הוא קלט טקסט ותשובה קולית,
דרך `POST /v1/bots/{bot_id}/turn`, עם אותו חשבון, פרומפטים, שיעורים ומכסות של הטלפון.
קישור תלמיד אינו מעניק גישה לממשק הניהול. הקישורים אינם נשלחים אוטומטית ללקוחות.

בקריינות אפשר לייצר, לשמוע ולהוריד WAV חד־ערוצי ב־8kHz דרך Gemini.
יש לבדוק הגייה ונוסח לפני העלאה לקו. שינוי טקסט פוסל את הקובץ הקודם להורדה.
העלאה אוטומטית לטכנוליין, זרימות הקשה/כוכבית וסליקה אוטומטית דורשות חיבור חיצוני נוסף.
אין לפרש אישור טקסט בספרייה כהקלטה שפורסמה בשלוחה.

הדוח העסקי מפריד בין תקבולים שהמנהל רשם, עלויות AI משוערות והנחות תחזית.
מחירים כוללים מע״מ; ההמרה לשקלים והמע״מ הם קלטי מנהל ניתנים לעריכה.
עלות תרגומון למשתמש שאינו משלם מסווגת כהוצאות פרסום ואינה מתווספת פעמיים לסך העלויות.
LTV בפועל אינו מוצג כעובדה לפני שנאספים נתוני שימור מספקים.
