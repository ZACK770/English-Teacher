# שדרוג חוויית הלומד: מעקב למידה מפורט, העלאת חומרי לימוד ומשחקונים אינטראקטיביים

תוכנית שדרוג מקיפה עבור אזור התלמיד של "דיבורא", המשלבת מעקב הישגים ושיחות עשיר, העלאת חומרי למידה מותאמים אישית (המוזרקים אוטומטית גם לשיעור הטלפוני), וספריית משחקוני תרגול אינטראקטיביים ייעודיים.

## User Review & Critical Decisions

> [!IMPORTANT]
> להלן ההחלטות העיקריות שאופיינו בהתאם לבקשותיך והתשובות שמסרת:

- **אימות כל פורמטי המשחקונים (Confirmed)**: הממשק יכלול 4 משחקונים אינטראקטיביים ייעודיים:
  1. *Word Match (התאמת מילים ופירושים)* — גרירה וחיבור מהיר של אוצר מילים שנלמד.
  2. *Sentence Builder (בניית משפטים)* — סידור אריחי מילים באנגלית לפי סדר דקדוקי נכון עם משוב מיידי.
  3. *Audio Listening Quiz (אתגר שמיעה והגייה)* — האזנה למשפט באנגלית עם קול הבוט ובחירת התשובה הנכונה.
  4. *Scenario Roleplay Dialogue (דיאלוג תרחיש מודרך)* — השלמת שיחה לפי תרחיש (עבודה, נסיעות, מסעדה).
- **העלאת חומרי לימוד וסנכרון מלא לקו הטלפוני (Confirmed)**: התלמיד או המנהל יוכל להעלות טקסט, רשימות אוצר מילים ונושאים. המערכת מפרקת אותם ליחידות לימוד מוגדרות ("Custom Study Units"), שומרת אותם בפרופיל התלמיד, ומזריקה אותם ישירות לתוך הפרומפט וה-Context של הבוט בשיחה הטלפונית הבאה (PBX/Web).
- **מעקב למידה עמוק ומפורט ("כל מה שהוצע") (Confirmed)**: תיעוד מלא של כל שיחה ומשחקון — תמליל שלב-אחר-שלב, השמעת אודיו, ציון יעד, ניתוח שגיאות ותיקונים עדינים, אוצר מילים שנרכש, גרף התקדמות שטף דיבור ומדד ביטחון, ונקודות מצטברות.

## 1. Overview & Core Concept

### מה המערכת מספקת
שדרוג אזור התלמיד (`/learn`) מסביבת שיחה פשוטה למרכז למידה דיגיטלי אינטראקטיבי ועשיר:
- **מרכז חומרי לימוד מותאמים ("החומרים שלי")**: העלאת טקסטים, מילים ושיעורים מותאמים אישית, הגדרת רמת קושי ומטרת השיעור, וסנכרון אוטומטי למורה הטלפוני.
- **מעקב שיחות מעמיק (Analytics & Deep Trace)**: הצגת כל שיחה שהתקיימה (בטלפון או באתר), תמליל מלא דו-לשוני, כפתורי שמע להאזנה לתשובות המורה, ניתוח שגיאות דקדוקיות והצעות שיפור.
- **ארנה למשחקוני למידה (Interactive Learning Games)**: 4 משחקונים אינטואיטיביים לחיזוק אוצר המילים, דקדוק ושמיעה, שמעניקים נקודות ומעדכנים את פרופיל הלמידה.
- **סנכרון דו-כיווני עם ה-PBX הטלפוני**: כשהתלמיד מחייג ל-`99/1` או `99/5`, המערכת מזהה את חומר הלימוד הפעיל שנבחר באתר ומתאימה את השיחה לקולו והנחיותיו של החומר הנבחר.

## 2. User Experience & Visual Design

### Key User Flows

```
┌────────────────────────────────────────────────────────────────────────┐
│                   זרימת החוויה של התלמיד (Learner Journey)             │
└────────────────────────────────────────────────────────────────────────┘
       │
       ▼
 1. התחברות מהירה (קוד אישי / קישור הזמנה ישיר)
       │
       ├──────────────► 2. דשבורד למידה אישי: מדדי שליטה, שעות תרגול,
       │                   גרף התקדמות ואוצר מילים שנרכש (Vocabulary Bank)
       │
       ├──────────────► 3. "חומרי הלימוד שלי": העלאת טקסט / רשימת מילים
       │                   ◄── בחירה: "הפוך לנושא השיחה הטלפונית הבאה"
       │
       ├──────────────► 4. מתחם משחקוני למידה (Game Arena):
       │                   ◄── Word Match / Sentence Builder / Listening Quiz
       │
       └──────────────► 5. יומן שיחות מפורט: תמלילים, האזנה לאודיו,
                           שגיאות שתוקנו ומשוב אישי מהמורה (Maya / Alex)
```

### Visual Identity & Theme
- **פלטת צבעים**: התבססות על שפת העיצוב המקורית של "דיבורא" ברוח טבעית ויוקרתית:
  - קנבס ראשי נקי ובהיר (`#F5F6F8` / `#FFFFFF`)
  - ירוק אורן מתוחכם לפעולות ראשיות וסטטוס פעיל (`#137C69`, רקע רך `#E9F5F0`)
  - נייבי-אינדיגו עמוק לכותרות וכרטיסי לילה (`#102D32`)
  - מבטא פיסטוק-ליים עדין לאלמנטים גרפיים וציונים (`#DCEAB7`)
- **טיפוגרפיה**: גופני Google Fonts בעברית (Assistant + Rubik) המבטיחים קריאות מושלמת, מספרים טבולריים (`tabular-nums`) עבור זמנים, ציונים ונקודות.
- **משוב אינטראקטיבי ותנועה**: חיווי מיידי בהצלחה במשחקונים (אנימציית כרטיס מתהפך, צליל הצלחה, צבירת נקודות חיה), חיווי טעינה וסנכרון מול שרת הטלפוניה.

## 3. Key Product Decisions & Trade-Offs

### 1. פורמט חומרי הלימוד והזרקתם לפרומפט הטלפוני
- **ההחלטה**: חומרי הלימוד נשמרים כמבנה של: כותרת, רשימת מונחי מפתח (Target Vocab), דוגמאות משפטים (Key Sentences), והנחיה דידקטית למורה.
- **היתרון**: המודל בשיחה הטלפונית (Gemini Live) מקבל הנחיות מדויקות ותמציתיות ב-Setup Context, ללא עומס טוקנים או בלבול של תרגום מסמכים ארוכים.

### 2. אופן רינדור המשחקונים בצד הלקוח (Client-Side State)
- **ההחלטה**: מנועי המשחקונים נבנים ברכיבי React טהורים וקלי משקל, עם שמירה מיידית של ציונים ומשוב ל-Store המרכזי.
- **היתרון**: אפס זמני המתנה בטעינת משחקים, חוויה מהירה וחלקה בטלפון ובמחשב.

### 3. שילוב בין תמליל לטקסט ולשמע אמיתי
- **ההחלטה**: עבור כל פנייה של המורה, התלמיד יוכל לא רק לקרוא את התמליל המדויק אלא גם להפעיל נגן שמע (WAV / TTS) ולשמוע כיצד המורה הגתה את המשפט.

## 4. Technical Architecture & Data Strategy

```
┌────────────────────────────────────────────────────────────────────────┐
│                        מבנה הרכיבים והזרימה                           │
└────────────────────────────────────────────────────────────────────────┘

 [ Learner Portal (/learn) ]
       │
       ├──► [ LearnerHeader & Stats ] (נקודות, רצף ימים, דקות שיחה, חבילות)
       │
       ├──► [ LearningMaterialsManager ]
       │       │── הוספת חומר חדש (הדבקת טקסט / מילים / נושא שיעור)
       │       └── סימון "חומר פעיל לשיחה הטלפונית הבאה"
       │
       ├──► [ GameArena ]
       │       ├── WordMatchGame (גרירת זוגות עברית-אנגלית)
       │       ├── SentenceBuilderGame (סידור מילים למשפט שלם)
       │       ├── ListeningQuizGame (האזנה לבוט ובחירת מענה)
       │       └── RoleplayDialogGame (שיחת תרחיש לפי שלבים)
       │
       ├──► [ CallHistoryDetailView ]
       │       ├── תמליל שלב-אחר-שלב (בוט / תלמיד)
       │       ├── נגן אודיו לכל תשובת מורה
       │       ├── כרטיסי שגיאות ותיקונים (Grammar & Accent coaching)
       │       └── סיכום פדגוגי בעברית + ציון שיעור
       │
       └──► [ LivePracticeRoom ] (חדר תרגול אינטראקטיבי ישיר באתר)
               └── סנכרון עם הבוטים (Maya, Alex, Translator)
```

### Data Models המתווספים
1. `StudyMaterial`:
   - `id`: מחרוזת מזהה
   - `customer_id`: שיוך לתלמיד
   - `title`: כותרת החומר
   - `topic`: נושא (עבודה, נדל"ן, שיחת היכרות, רפואה וכו')
   - `raw_text`: טקסט המקור
   - `vocabulary`: מילים וביטויים באנגלית ותרגומם
   - `key_phrases`: משפטי מפתח לשימוש בשיחה
   - `is_active_for_phone`: האם מופעל בשיחה הבאה בקו
2. `GameScoreRecord`:
   - `id`, `customer_id`, `game_type`, `score`, `points_earned`, `accuracy_pct`, `completed_at`
3. `CallTurnDetail`:
   - `speaker`: 'learner' | 'tutor'
   - `text`: תמליל
   - `audio_url`: שמע
   - `corrections`: מערך תיקונים עדינים והסברים בעברית
